# Clicky Cookie

## Overview

Clicky cookie is a fast-paced cookie collecting game! You need to have quick instincts and click on a cookie to collect it before it disappears and avoid the bombs.

## Development

This project was a collaborative at home game jam. 

- Artwork drawn by McQuistan Jones
- Background and endgame audio by McQuistan Jones
- Meows by Buttercup
- Programming by David Jones
